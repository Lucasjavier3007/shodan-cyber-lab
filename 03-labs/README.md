# Hands-on Labs

This section contains practical exercises performed with Shodan.

Each laboratory follows a structured methodology:

1. Objective
2. Methodology
3. Query or technique
4. Results
5. Analysis
6. Security implications
7. Mitigation
8. Key learnings

Sensitive information, credentials, personal data, and unauthorized target information will not be published.

---

> Goal: turn theoretical knowledge into practical cybersecurity skills.
